# lambdabuild Provider

Builds deterministic AWS Lambda zip Artifacts (functions and layers) from uv-managed Python projects.
uv is embedded in the provider binary, so no Python tooling is needed on the runner.

- **Same inputs, same bytes, on every host.** A zip built on macOS, Linux or Windows has the same SHA-256, so `source_code_hash` changes only when your code or `uv.lock` does.
- **Plan computes, apply builds.** Plan hashes the inputs into the Input fingerprint; apply builds the zip. Saved plans apply on another runner.
- **Built for Lambda.** Linux wheels for `x86_64` or `arm64` and Python 3.11 to 3.14, function or layer layout, a CycloneDX SBOM beside every zip.

New here? Start with the **Getting started** guide. The **CI/CD pipelines**, **Private indexes and restricted networks**, **Reproducible builds** and **Troubleshooting** guides cover running it in production.

## Example Usage

```terraform
provider "lambdabuild" {
  # All arguments are optional. Shown: share the toolchain cache across jobs.
  cache_dir = "/var/cache/lambdabuild"
}
```

## Private indexes and credentials

Provider arguments are stored in state, in plan JSON and in saved plan files, so `index_url`, `extra_index_urls` and `python_install_mirror` must not contain credentials (`https://user:password@...` is rejected). Give the index a name and put the credentials in the environment of the process that runs Terraform:

```hcl
provider "lambdabuild" {
  index_url = "corp=https://pypi.corp.example/simple"
}
```

```sh
export UV_INDEX_CORP_USERNAME=svc-builder
export UV_INDEX_CORP_PASSWORD=...
```

An index declared in the project's `pyproject.toml` (`[[tool.uv.index]] name = "corp"`) uses the same variables. Proxies (`HTTPS_PROXY`), certificates (`SSL_CERT_FILE`, `native_tls`) also come from the environment; other `UV_*` variables are ignored so every host builds alike, and uv's errors are redacted before they reach Terraform.

## Schema

### Optional

- `cache_dir` (String) Where uv is extracted and managed Python is installed. Must allow executing binaries. Defaults to the user cache dir + /lambdabuild.
- `extra_index_urls` (List of String) Additional package indexes (uv's UV_INDEX): URLs, or named indexes "name=url". Must not contain credentials: name the index and set UV_INDEX_<NAME>_USERNAME and UV_INDEX_<NAME>_PASSWORD in the environment.
- `index_url` (String) Default package index (uv's UV_DEFAULT_INDEX): a URL, or a named index "name=url". Must not contain credentials: name the index and set UV_INDEX_<NAME>_USERNAME and UV_INDEX_<NAME>_PASSWORD in the environment.
- `native_tls` (Boolean) Trust the OS certificate store (UV_NATIVE_TLS). Default false.
- `offline` (Boolean) Use only the local cache (UV_OFFLINE). Default false.
- `python_install_mirror` (String) Mirror for managed Python builds (UV_PYTHON_INSTALL_MIRROR). Must not contain credentials.
- `uv_cache_dir` (String) Wheel and package cache shared across builds. Defaults to uv's own default.
- `uv_path` (String) Use an external uv binary instead of the embedded one.
